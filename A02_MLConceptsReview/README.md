🔑 Key Concepts Covered
1. Training vs Validation Phase

Training fits the model to data by minimizing a loss function.

Validation evaluates generalization on unseen data.

Typical split: 70% train, 15% validation, 15% test.

Prevents overfitting and information leakage.

2. Underfitting vs Overfitting

Underfitting → model too simple, fails to capture patterns.

Overfitting → model memorizes noise, fails to generalize.

Solutions:

Reduce underfitting → increase complexity or train longer.

Reduce overfitting → regularization, dropout, more data.

3. Classification vs Regression

Classification predicts discrete categories (spam/not spam, digit classes).

Regression predicts continuous values (house prices).

Evaluation metrics vary: accuracy, recall, etc.

4. Confusion Matrix

Summarizes model performance using TP, FP, TN, FN.

Helps diagnose errors such as high false negatives.

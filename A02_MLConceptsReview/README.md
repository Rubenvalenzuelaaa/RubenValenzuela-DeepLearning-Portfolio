# A02 — Machine Learning Concepts

This project provides a structured overview of core machine learning concepts, serving as a foundation for understanding how ML models learn, make predictions, and generalize to new data. The assignment covers definitions, examples, and explanations of key principles used throughout modern AI and data science workflows.

## 📄 Included File
- `finalMLconcepts.pdf` — Summary explaining fundamental ML concepts.

## 🔑 Key Topics
- Supervised vs. Unsupervised Learning  
- Regression vs. Classification  
- Bias–Variance Tradeoff  
- Overfitting & Underfitting  
- Training vs. Testing Data  
- Model Evaluation Metrics  
- Generalization and model performance  

## 🎯 Learning Outcomes
- Build foundational intuition for how ML models operate  
- Understand why models succeed or fail based on data and structure  
- Identify common pitfalls such as overfitting and underfitting  
- Prepare for deeper coursework in neural networks and deep learning  


Compare classification and regression tasks and their metrics.

Interpret confusion matrices and precision-recall curves.

These concepts form the foundation for all advanced deep learning work.

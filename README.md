# Ruben Valenzuela — Deep Learning Portfolio (ITAI 2376)

This repository contains all major projects, labs, written assignments, and model implementations completed during the course **ITAI 2376 – Deep Learning** at Houston Community College.  
It showcases my technical growth across neural networks, TensorFlow/Keras workflows, convolutional architectures, hyperparameter tuning, diffusion models, and a final AI Agent Creation project.

The portfolio demonstrates practical machine learning implementation, structured documentation, and professional coding practices suitable for both academic evaluation and industry portfolios.

---

## 📂 Repository Structure & Project Descriptions

### **A02 — Deep Learning Frameworks Overview**
A comparative analysis of major deep learning frameworks, including:
- TensorFlow  
- Keras  
- PyTorch  

Includes strengths, weaknesses, and industry use cases.

---

### **A02b — Machine Learning Concepts Review**
A technical review summarizing foundational ML concepts:
- Bias vs. Variance  
- Underfitting vs. Overfitting  
- Gradient Descent Optimization  
- Cost/Loss Functions  
- Evaluation Metrics  

---

### **A03 — Neural Network Zoo**
A visual and conceptual overview of neural network architectures:
- Perceptrons  
- Multi-Layer Perceptrons  
- Convolutional Neural Networks  
- Recurrent Neural Networks  
- Transformers  

Includes diagrams and explanation of how each architecture processes data.

---

### **A04 — Deep Learning for an 11-Year-Old**
A simplified teaching project explaining complex deep learning concepts so that an 11-year-old can understand them.  
Includes metaphors, illustrations, and accessible explanations.

---

### **A05 — Analyzing *Arrival* Through the Lens of NLP**
An academic paper analyzing the movie *Arrival* using NLP theory.  
Topics explored:
- Linguistic relativity  
- Nonlinear communication  
- Symbolic vs. sub-symbolic processing  
- Language modeling insights  

---

### **L02 — No-Code Deep Learning Tools**
A hands-on exploration of no-code platforms such as Teachable Machine.  
Includes model training, testing, and a reflection on accessibility in AI/ML.

---

### **L04 — Convolutional Neural Networks (CNN Lab)**
A TensorFlow/Keras implementation involving:
- Image preprocessing  
- Model building  
- Training & validation  
- Accuracy/loss tracking  
- Final evaluation  
- Reflection journal  

---

### **L08 — Hyperparameter Tuning Lab**
Extensive tuning experiments altering:
- Learning rate  
- Batch size  
- Optimizers  
- Activation functions  
- Regularization strategies  

Includes comparisons, model metrics, and conclusions on best-performing configurations.

---

### **Midterm Project — Diffusion Models**
A full midterm project focused on image generation using diffusion models.  
Contents include:
- A Jupyter Notebook implementing diffusion pipelines  
- A technical report explaining the underlying theory  
- Generated examples  
- A reflective write-up on real-world applications  

---

### **Final Project — AI Agent Creation**
A comprehensive AI Agent system designed as the capstone for the course.  
Includes:
- System architecture  
- Reasoning/Planning module  
- Memory subsystem (short-term & long-term)  
- Tools & action execution pipeline  
- Output formatting logic  
- Jupyter Notebook implementation  
- Full PDF technical report  
- Demonstration video  

This final project integrates concepts from the entire semester into a functional intelligent agent.

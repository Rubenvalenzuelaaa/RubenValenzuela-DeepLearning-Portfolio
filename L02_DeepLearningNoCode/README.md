# L02 — Exploring Deep Learning Tools: A No-Code Introduction to TensorFlow & Keras

This project provides an introductory, no-code exploration of deep learning using TensorFlow and Keras.  
The lab focuses on using a visual interface to experiment with the VGG16 convolutional neural network, observe predictions, and develop foundational intuition for deep learning workflows.

## 🧠 Key Topics
- Basics of deep learning and neural networks  
- VGG16 pre-trained CNN architecture  
- Image classification with ImageNet  
- Sensitivity of models to image variations  
- Model interpretability and prediction confidence  
- Importance of input preprocessing  

---

## 🎓 Learning Outcomes
- Understand how deep learning models such as VGG16 process images  
- Develop intuition for how prediction confidence changes with different inputs  
- Gain experience analyzing model behavior without writing code  
- Strengthen understanding of transfer learning and pre-trained models  
- Reflect on interpretability and real-world model limitations  

---

## 📝 Reflection Summary
This lab introduced deep learning through an accessible, no-code interface, making complex concepts intuitive.  
By testing different images and observing prediction changes, we gained insight into:

- How CNNs extract hierarchical features  
- How preprocessing affects outcomes  
- Why explainability is crucial in AI systems  

The experience strengthened confidence in navigating deep learning tools and highlighted how pre-trained models can be applied in academic and real-world environments such as game development or computer vision applications.

# A03 — Neural Network Zoo

This project presents a visual and conceptual exploration of different types of neural networks by using an analogy inspired by biological systems—in this case, an ant colony.

The infographic **“ANT-EON ZOO: The Neural Nest”** provides a simplified yet powerful comparison of neural network capabilities and limitations through the metaphor of the *forward-marching* and *fixed-path* ant behaviors.

## 🐜 Project Overview

The infographic highlights:

### **Capabilities — The Forward March**
Neural networks that:
- Follow structured, sequential data flows  
- Learn through multi-layer propagation  
- Pass information forward without loops  
- Excel in classification and regression tasks  

### **Limitations — The Fixed Path**
Neural networks that:
- Cannot adjust to new data without retraining  
- Depend heavily on fixed architecture  
- Struggle with pattern changes or sequential variation

## 🧱 Structure, Mechanics, and Applications

The bottom section of the infographic breaks down:
- **Structure:** Layers, weights, activation, forward pass  
- **Mechanics:** Gradient descent, loss optimization  
- **Applications:** Image classification, text processing, recommendation systems, etc.  

These elements help contextualize how neural networks operate and where they’re most effective.

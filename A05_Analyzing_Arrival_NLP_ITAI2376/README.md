## 🧠 Key Insights From the Report

### **🔹 Ambiguity Is the True Antagonist**  
The "weapon/tool" misunderstanding mirrors real NLP ambiguity problems — identical to how models misinterpret words like *bank*, *charge*, *fair*, etc.

### **🔹 Heptapod Language = Transformer Architecture**  
- Holistic, simultaneous understanding  
- Parallel processing  
- No sequential ordering required  

This perfectly illustrates the leap from RNN → Transformer.

### **🔹 Static Models Always Fail**  
Louise’s early dictionary behaves like a Word2Vec embedding:  
1 token = 1 fixed meaning → leads to disaster.

Only contextual embedding (BERT-style) solves meaning.

### **🔹 Theoretical Innovation Proposed**  
The assignment suggests a new architecture layer:

**CUQ Layer — Contextual Uncertainty & Querying**  
- Detects ambiguity  
- Flags uncertainty  
- Asks for clarification before making a decision  

A direct safety-inspired design based on the events of the film.

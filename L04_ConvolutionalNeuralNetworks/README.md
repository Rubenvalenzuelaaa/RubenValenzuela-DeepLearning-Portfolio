# L04 — Convolutional Neural Networks (CNN)

This lab focuses on the implementation, training, and evaluation of Convolutional Neural Networks (CNNs) for image classification tasks. The project includes hands-on experimentation with convolutional layers, model tuning, visualization of results, and a written reflection to demonstrate conceptual understanding.

---

## 📄 Included Files
- **Lab04_CNN_RubenValenzuela_ITAI2376.pdf**  
- **Lab04_Reflection_RubenValenzuela_ITAI2376.pdf**

---

## 🔑 Key Topics Covered
- Convolutional layers & kernels  
- Max Pooling operations  
- Feature extraction and hierarchical learning  
- Activation functions (ReLU)  
- CNN architecture design  
- Training and validation performance curves  
- Confusion matrix interpretation  
- Overfitting vs. underfitting  

---

## 🎯 Learning Outcomes
Through this lab, I developed the ability to:

- Understand how CNNs extract visual features from images.  
- Build and train a CNN using deep learning frameworks.  
- Analyze model performance using accuracy/loss plots and confusion matrices.  
- Identify and mitigate training challenges such as overfitting.  
- Summarize insights through a structured reflection document.

---

## 🧠 Reflection Summary
This lab strengthened my understanding of how convolution and pooling operations work together to build increasingly complex visual representations. It highlighted the importance of hyperparameter tuning, architecture choices, and data preprocessing for improving CNN performance.

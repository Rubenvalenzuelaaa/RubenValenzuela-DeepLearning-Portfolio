# A02 — Comparative Analysis: TensorFlow vs PyTorch

This project explores a comparative analysis of the two most widely used deep learning frameworks: TensorFlow and PyTorch. It includes a written report and a professional presentation covering technical differences, usability, ecosystem strengths, and industry adoption.

## 📄 Included Files
- A02a_AIAIchemists_Rubenvalenzuela_ITA2376.pptx  
- A02b_AIchemists_RubenValenzuela_ITA2376.docx  

## 🔧 Key Topics
- TensorFlow vs PyTorch  
- Computational graphs (static vs dynamic)  
- GPU/TPU acceleration  
- Model deployment pipelines (TF Serving, TorchScript)  
- Framework ecosystem and scalability  

## 🎯 Learning Outcomes
- Understand how each framework handles model creation and training  
- Evaluate which framework is better for research vs production  
- Build foundational intuition for future deep learning projects
